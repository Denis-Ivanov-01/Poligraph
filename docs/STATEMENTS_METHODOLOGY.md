# Statements Methodology

This document points to the methodology used for public statement analysis.

The current methodology content lives in:

- [`resources/bg-BG/statements-methodology.md`](../resources/bg-BG/statements-methodology.md)

That file is served by the backend public resources API and rendered by the public methodology page. It is the canonical editable methodology resource for the application.

The statement methodology explains:

- the three evaluation dimensions;
- how factual claims are separated from opinions, promises, and predictions;
- how uncertainty is handled;
- how double-counting is avoided;
- the role and limitations of AI;
- correction and transparency principles;
- source standards and evidence expectations.

Statement methodology should remain readable for the public, not only for developers. Locale-specific public methodology content should live under `resources/<locale>/`.
